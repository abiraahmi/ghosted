# Changelog

## ghosted 0.1.0.0 (2026-03-04)

- single function app where redactions and all complementing options are
  made through a shiny app.

## ghosted 0.0.2.0 (2026-03-04)

- [`ghost()`](https://abiraahmi.github.io/ghosted/reference/ghost.md) is
  the user-facing interface for local app-based transcript
  deidentification.
- Leading speaker names at line start are normalized to
  `Interviewer`/`Participant`; names elsewhere are redacted.
- The app supports batch processing and flexible output formats across
  input types.
- VTT conversion from DOCX/TXT writes cues without timestamps.
- README and vignette describe the app workflow.
